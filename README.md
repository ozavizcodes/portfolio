# Faith Abraham — Software Engineer & Emerging AI Engineer

An impact-first personal portfolio built with React, TypeScript, Vite, Tailwind CSS, and Framer Motion.

## Local development

```bash
npm install
npm run dev
```

Open [http://localhost:3001](http://localhost:3001).

## Validate a change

```bash
npm run check
```

This runs the TypeScript check and production build.

## Site content

All portfolio copy and public links live in [src/content/portfolio.ts](src/content/portfolio.ts). Update this file before editing visual components.

## Before publishing

- Add a public résumé PDF and its link.
- Replace each selected-work summary with a non-confidential outcome or metric.
- Add one or two public AI project case studies with a demo and source repository.
- Connect a custom domain and configure analytics/privacy information if you choose to use analytics.
